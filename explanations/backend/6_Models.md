# Models (JPA Entities)

## 1. What are Models?
In Spring Boot, Models (or Entities) are Java classes that represent actual tables in our PostgreSQL database. Every object of this class represents a single row in the database.

## 2. Key Annotations
- **`@Entity`:** Tells Hibernate (our ORM tool) to map this class to a database table.
- **`@Table(name="...")`:** Explicitly names the table.
- **`@Id` & `@GeneratedValue(strategy = GenerationType.IDENTITY)`:** Defines the Primary Key and tells the database to auto-increment it (1, 2, 3...).
- **`@Column`:** Used to customize specific columns (e.g., `unique=true`, `nullable=false`).

## 3. Relationships
Databases are relational. We define these relations directly in Java:
- **`@ManyToOne` & `@JoinColumn`:** A `Transaction` belongs to one `Company`. An `Upload` belongs to one `Company`.
- **`@OneToMany`:** A `Company` can have many `Upload`s.
When we query a `Transaction`, Hibernate automatically knows how to fetch the associated `Company` data using an SQL `JOIN` behind the scenes!

## 4. The Vector Column
In `AnomalyResult.java`, we define:
```java
@Column(columnDefinition = "vector(768)")
private String embeddingText;
```
This is a custom column type provided by the `pgvector` extension. It allows us to store the mathematical array (vector) generated by Google Gemini directly in PostgreSQL!
